# User prompt — una conciliación

```
Conciliá el período indicado.

EXTRACTO:  extracto-<<AAAA-MM-DD>>.csv
FACTURAS:  facturas-abiertas-<<AAAA-MM-DD>>.csv
PERIODO:   << desde >> a << hasta >>

Devolvé el array JSON según el formato del system prompt.
Antes del array, en una línea: cuántos movimientos acreditados leíste y
cuántos quedaron conciliados, parciales y sin match.
```
